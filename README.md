# CO₂ Solubility Prediction using Machine Learning

Course Project – DA1100

## Overview
Developed machine learning models to predict CO₂ solubility in ionic liquids using molecular descriptors derived from SMILES representations.

## Techniques Used
- Python
- Pandas
- NumPy
- RDKit
- Random Forest
- XGBoost

## Workflow
1. Feature extraction from molecular structures
2. Data preprocessing
3. Feature engineering
4. Model training
5. Performance evaluation
